# ChemQuest

ChemQuest is an interactive chemistry learning website designed to help students learn and review chemistry concepts from Grade 7 to Grade 12.

Each topic includes explanations, examples, diagrams, and quizzes to test your understanding.

Live site: https://chemquest.vercel.app/

# Motivation
I started as a tutor during the COVID-19 pandemic, where I saw firsthand how difficult it was to engage students through Zoom. I proposed developing an e-learning platform to make online learning more interactive. Collaborating with the administration, I incorporated feedback through regular meetings. The platform was integrated into the academy’s main website and has been used by more than 200 students in workshops and at home. Seeing something I built solve a real problem for students was what first sparked my interest in software development and continues to motivate me to build technology that people find useful.


## Features

- Chemistry lessons with examples and diagrams
- Interactive quizzes after each section
- Gem reward system for completing quizzes
- Tracks your progress
- Covers chemistry topics from Grade 7–12 with simple explanations

## Topics

ChemQuest currently includes:

- Atom Structure
- Elements and the Periodic Table
- Chemical Diagrams
- Ionic Bonds
- Covalent Bonds
- Chemical Equations
- Chemical Reactions
